# 陈希孺《概率论与数理统计》

陈希孺先生是中国统计学界的泰斗，其《概率论与数理统计》教材以思想深刻、论述清晰著称。相比茆诗松版本，陈希孺的教材更侧重统计思想的阐释，适合有一定基础后深入理解概率统计的本质。
