# 数据结构

数据结构是计算机科学的基石，也是经济统计学生走向互联网技术研发岗位的必经之路。无论是面试中的算法题，还是工作中的数据处理与模型开发，扎实的数据结构功底都能让你事半功倍。

---

## 王卓《数据结构与算法基础》

王卓老师（青岛大学）的这门《数据结构与算法基础》是B站上播放量最高的数据结构课程，累计播放超千万。课程以严蔚敏《数据结构（C语言版）》为教材，覆盖了考研和面试所需的全部核心知识点。

王卓老师的讲解**细致入微、板书清晰**，即使没有C语言基础也能跟上。每节课聚焦一个小知识点（10~20分钟），适合碎片化学习。

### 课程大纲

课程按照严蔚敏教材的章节组织，核心内容覆盖：

1. **绪论**：数据结构基本概念、算法与算法分析
2. **线性表**：顺序表、单链表、循环链表、双向链表
3. **栈与队列**：顺序栈、链栈、循环队列、链队
4. **串、数组与广义表**：串的模式匹配（KMP）、特殊矩阵压缩存储
5. **树与二叉树**：二叉树遍历、线索二叉树、哈夫曼树、树与森林
6. **图**：图的存储、DFS/BFS、最小生成树、最短路径（Dijkstra/Floyd）、拓扑排序、关键路径
7. **查找**：顺序查找、二分查找、二叉排序树、平衡二叉树（AVL）、散列表（哈希）
8. **排序**：插入排序、希尔排序、冒泡/快速排序、选择/堆排序、归并排序、基数排序

### 学习建议

1. **按顺序观看，不要跳**：数据结构的前后章节依赖关系很强，跳过硬看后面的会很吃力
2. **每看完一节就写代码**：算法光看是学不会的，务必打开IDE把讲过的结构自己实现一遍
3. **配合刷题**：学完每个专题后去 LeetCode 刷对应标签的题目，推荐从「简单」难度开始
4. **不需要学C语言全部语法**：能看懂变量声明、指针、结构体、函数定义就足够跟上课程了
5. **替代方案**：如果你更习惯 Java/Python，学完王卓的算法思想后，可以看对应的 Java/Python 实现版本（B站搜索「数据结构 Java/Python 实现」即可）

## 为什么经统学生要学数据结构？

- **面试刚需**：数据分析师、算法工程师的技术面，手撕算法题是标配
- **思维训练**：递归、分治、动态规划这些思想，和统计中的MCMC、EM算法有着深层的思维共鸣
