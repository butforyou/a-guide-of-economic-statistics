# 必要工具

工欲善其事，必先利其器。以下整理了经济统计学习和工作中常用的工具，详细的使用指南会逐步补充完善。

---

## 文本编辑与笔记

### VS Code

现代代码编辑器的标杆，轻量、扩展丰富、跨平台。Python、R、LaTeX、Markdown 均有高质量插件支持。

- 官网：[code.visualstudio.com](https://code.visualstudio.com/)
- 推荐插件：Python、Jupyter、LaTeX Workshop、Markdown All in One、GitLens

### Typora / Markdown

Markdown 是技术写作的标准格式——课程笔记、项目文档、技术博客，乃至本指南的所有内容都是用 Markdown 编写的。Typora 是目前体验最好的 Markdown 编辑器之一。

- Typora 官网：[typora.io](https://typora.io/)
- Markdown 语法参考：[Markdown Guide](https://www.markdownguide.org/)

## 版本控制

### Git & GitHub

Git 是软件开发的事实标准版本控制系统，GitHub 是全球最大的代码托管平台。无论是课程作业管理还是团队协作，Git 都是绕不开的基础工具。

- Git 官网：[git-scm.com](https://git-scm.com/)
- 推荐教程：[Learn Git Branching](https://learngitbranching.js.org/)（交互式学习）

## AI 工具

### API 与 Agent

现代经济统计工作中，AI API 的调用和 Agent 的搭建正在成为核心技能。从批量数据处理到自动化分析报告，善用 API 可以成倍提升效率。

## 环境与系统

### Linux / WSL

Linux 是数据科学和机器学习的事实标准运行环境。Windows 用户可以通过 WSL（Windows Subsystem for Linux）在不装双系统的情况下获得完整的 Linux 体验。

- WSL 安装指南：[微软官方文档](https://learn.microsoft.com/zh-cn/windows/wsl/install)
- 推荐发行版：Ubuntu

### Conda / 包管理

Python 生态的包管理和环境隔离工具，避免不同项目之间的依赖冲突。

- Miniconda 官网：[docs.anaconda.com/miniconda](https://docs.anaconda.com/miniconda/)

---

## 科学计算与可视化

### Jupyter Notebook / Lab

交互式编程环境，是数据分析和统计建模的标准工作台。支持代码、公式、图表、文字混排，特别适合探索性数据分析。

### Python 科学计算栈

- NumPy：数值计算基础
- Pandas：表格数据处理
- Matplotlib / Seaborn：统计图表绘制
- Scikit-learn：经典机器学习算法库

### R / RStudio

统计分析的经典工具链。虽在机器学习领域被 Python 追赶，但在学术统计和生物统计领域仍是主流。
